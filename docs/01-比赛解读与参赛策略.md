## 二、评分拆解与得分策略

总分 100 + 社媒最高 30。

### 1. 创意与场景价值（35 分）
> 创意是否鲜明，能否满足实际需求或提供有吸引力的玩法。

策略：不做"待办清单 / 番茄钟 / 聊天机器人"这类已经被做烂的选题。选一个**有真实痛点、但没人把它做成产品**的场景：

**把"复刻别人的界面"这件苦力活，做成一条 3 秒的编译流水线。**
前端/设计同学拿到一张截图想复刻它的设计语言，过去要做四件事：吸色、量间距、猜层级、验对比度，半小时起步，还经常量错。本作品把截图当"源码"，反向编译成一套可用的 Design Token。

- 场景价值：D2C / 设计走查 / 竞品分析 / 老旧系统重构取色，都是高频真实需求。
- 创意点：不是"取色器"（只能吸色），而是**带语义推断的反编译器**——它能说出"这个颜色是背景，那个是主色，间距基准是 8px，正文对比度不达标"。

### 2. 作品完成度（40 分，权重最高）
> 核心功能或玩法是否实现，作品能否正常运行。

策略：**把"跑不起来"的概率降到 0**。

- 零后端、零依赖、零构建：纯静态页面，不依赖任何 API Key、不依赖网络请求，评审点开即用。
- 全本地计算：图片不上传，`canvas` 里完成全部像素分析 → 断网也能跑，也没有隐私与审核风险。
- 每条结论都带置信度：识别不出间距时明确说"这张图不适合做间距分析"，而不是编一个假数字（评委最反感"看起来很智能其实在瞎猜"）。

### 3. 使用体验（25 分）
> 操作是否顺畅，界面与使用说明是否清晰。

策略：
- 首屏 3 秒内看懂这是什么：一句话定位 + 拖拽区 + 一键"试试示例"（评委不需要自己找图）。
- 支持拖拽 / 点击选择 / 直接 Ctrl+V 粘贴截图三种入口。
- 分析过程有阶段提示（采样 → 聚类 → 角色推断 → 体检），而不是一个转圈。
- 结果分层：先给"一句话结论"，再给可复制的 Token 代码，最后给方法论说明。
- 移动端可用，键盘可操作。

### 4. 社媒加分（最高 +30）
- 有效分享基础 +10：内容公开可见、链接可打开、带话题 `#WorkBuddy #1024程序员节`。
- 人气分 +5~20：按点赞+收藏总数分档（10-30 → 5 分；31-60 → 10 分；61-100 → 15 分；101+ → 20 分），11-02 统一核验。
- 应对：准备一套可直接发布的小红书/掘金图文（含 3 张截图 + 话题标签），由账号本人发布。

## 四、风险清单

1. **上墙延迟**：审核通过后 T+1 上墙，必须留出至少 2 天缓冲 → 10-25 就投，不拖到 10-31。
2. **截图违规**：示例图若是真实 App 截图，可能涉及第三方商标/隐私 → 全部自绘虚构产品。
3. **链接失效**：投稿前重新用无痕窗口打开体验链接自测一遍（规则明确要求"链接可正常打开"）。
4. **社媒链接无效**：必须公开可见 + 带话题，私密/仅粉丝可见不算有效分享。
